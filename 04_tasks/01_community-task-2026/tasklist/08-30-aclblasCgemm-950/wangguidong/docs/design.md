## 背景介绍

### Cgemm算子实现设计

Cgemm 用于复数矩阵乘累加，计算 `C = alpha × op(A) × op(B) + beta × C`。拟采用 Ascend C 开发，在 ops-blas 统一接口下支持列主序矩阵、不转置、转置与共轭转置。

### Cgemm算子接口与能力分析

复用 ops-blas 的 `aclblasCgemm` 声明，参数顺序与 `cublasCgemm` 对应，不新增产品专用接口。

```cpp
aclblasStatus_t aclblasCgemm(
    aclblasHandle_t handle, aclblasOperation_t transa, aclblasOperation_t transb,
    int m, int n, int k, const aclblasComplex* alpha, const aclblasComplex* A, int lda,
    const aclblasComplex* B, int ldb, const aclblasComplex* beta, aclblasComplex* C, int ldc);
```

| 参数 | 参数含义 | 数据类型 | 存储位置与约束 | 形状 |
| --- | --- | --- | --- | --- |
| handle | 库上下文及执行流 | aclblasHandle_t | 有效的主机侧句柄 | 标量 |
| transa、transb | A、B 的矩阵操作 | aclblasOperation_t | N、T、C 三种枚举 | 标量 |
| m、n、k | 输出行数、输出列数、归约长度 | int | 主机侧非负整数 | 标量 |
| alpha、beta | 乘积与原输出的系数 | const aclblasComplex* | 主机侧非空指针 | 各一个复数 |
| A | 左输入矩阵 | const aclblasComplex* | 设备侧列主序 | N：lda × k；T/C：lda × m |
| lda | A 的相邻列间隔，以复数元素计 | int | N：≥ max(1,m)；T/C：≥ max(1,k) | 标量 |
| B | 右输入矩阵 | const aclblasComplex* | 设备侧列主序 | N：ldb × n；T/C：ldb × k |
| ldb | B 的相邻列间隔，以复数元素计 | int | N：≥ max(1,k)；T/C：≥ max(1,n) | 标量 |
| C | 输入旧值并原地写回结果 | aclblasComplex* | 设备侧列主序 | ldc × n，逻辑区域 m × n |
| ldc | C 的相邻列间隔，以复数元素计 | int | ≥ max(1,m) | 标量 |

### Cgemm算子功能分析

输入为 A、B、alpha、beta 及必要时的 C 旧值，输出为原地更新后的 C。`op(A)` 的逻辑形状为 m × k，`op(B)` 为 k × n。

N 表示原矩阵，T 表示仅转置，C 表示转置并对虚部取反。两输入的操作类型独立选择；复数情况下 T 和 C 不可混用。

输入输出及系数均为 COMPLEX64，实部和虚部各为 FLOAT32。不涉及广播或批量矩阵运算。

# 需求分析

## 需求描述

设计符合官方任务要求的 Ascend 950PR 复数矩阵乘实现，覆盖合法矩阵尺寸、前导维填充、全部转置组合及边界输入。计算方法和任务分配仅由参数、数据布局与硬件资源决定，不依赖测试用例名称、随机种子或固定尺寸清单。

## 需求拆解

功能：实现复数矩阵乘累加及 N/T/C 语义，保持 C 的原地输出约定。

布局：支持合法 lda、ldb、ldc，包括紧凑存储和列间填充；仅更新 C 的逻辑区域。

边界：m 或 n 为零时不执行计算；k 为零或 alpha 为零时执行 `C = beta × C`；beta 为零时不读取 C 旧值。

参数检查：识别空句柄、非法操作类型、负维度、非法前导维和任务书规定的空指针错误，返回相应状态。

精度：按任务书对实部、虚部分别判定；分别评估 Netlib 与 OpenBLAS，不用一套结果替代另一套结果。

性能：通过通用分块、并行分配与搬运计算重叠减少开销，按官方测试指导逐用例评估。

# 详细设计

## 算子分析

### 数学公式

设 `X = op(A) = Xr + iXi`、`Y = op(B) = Yr + iYi`，拟将复数矩阵乘分解为四次实数矩阵乘：

```text
P1 = Xr × Yr        P2 = Xi × Yi
P3 = Xr × Yi        P4 = Xi × Yr
Zr = P1 - P2        Zi = P3 + P4
```

设 `alpha = ar + i ai`、`beta = br + i bi`、原输出 `C0 = Cr + i Ci`，则：

```text
Re(C) = ar × Zr - ai × Zi + br × Cr - bi × Ci
Im(C) = ar × Zi + ai × Zr + br × Ci + bi × Cr
```

四次实数矩阵乘中的归约沿 k 维进行。有限精度下，归约顺序可能影响结果，须按精度标准验证，不要求一般矩阵乘与参考实现逐位相同。

### 支持数据类型

接口使用 `aclblasComplex`，实部、虚部均为 FLOAT32。拟采用 FLOAT32 乘法与累加，不预设低精度转换或经验误差补偿。

### 支持形状

支持满足接口约束的 m、n、k，包括非方阵、非对齐尺寸、退化维度及合法前导维填充。以运行时参数确定计算范围，不限定为特定测试尺寸；实际可处理规模受可用设备内存和安全地址范围限制。

## 算子实现

### 实现方案

拟采用“参数检查与任务划分—复数分量整理—实数矩阵乘—复数合成与写回”的流程。矩阵乘由 Cube 执行，数据整理、系数组合及边界缩放由 Vector 执行；各阶段在句柄绑定的执行流中按依赖关系调度。

#### 3.2.1 host侧设计：

先校验句柄、操作枚举、维度、前导维及系数指针。空句柄返回 `ACLBLAS_STATUS_HANDLE_IS_NULLPTR`，非法枚举返回 `ACLBLAS_STATUS_INVALID_ENUM`，其余非法参数返回 `ACLBLAS_STATUS_INVALID_VALUE`。

通过基础校验后，m 或 n 为零直接返回成功，不访问矩阵。非空输出要求 C 指针有效；k 大于零时按任务书要求检查 A、B 非空。alpha 为零不放宽任务书规定的指针约束。

k 为零或 alpha 为零时选择缩放流程：beta 为零仅写零，beta 为一保持 C，其他 beta 进行复数缩放。其余情况选择矩阵乘流程。成功返回表示调用成功，读取设备结果前仍需同步执行流。

##### 1. 分核策略：

拟将输出的 m、n 维切成二维块，依据有效块数及可用计算核数分配任务。每个输出块具有明确的写入归属，不允许多个核无协调地更新同一输出区域。

优先沿输出块并行；输出块不足时评估沿 k 维分段的收益。若采用分段归约，需为部分和分配独立空间，并按明确顺序合并，综合考虑额外访存、归约开销及精度影响。

##### 2. 数据分块和内存优化策略：

拟根据 Cube 对齐要求、片上存储容量、数据类型及缓冲数量推导块大小。缓冲区预算同时包含输入、累加结果、数据整理和写回所需空间，不以某个测试尺寸决定配置。

按原矩阵的前导维读取有效元素，将交错存储的实部、虚部分离为可供实数矩阵乘使用的布局；转置通过地址映射或搬运布局处理，共轭通过虚部取反处理。补齐区域填零，避免读取输入填充内容参与计算。

采用分块搬运及双缓冲时，须保证覆盖旧缓冲前其消费者已经完成，读取新缓冲前数据已经就绪。输出阶段仅写入有效行列，保持 C 的列间填充不变。

临时空间规模按输入分量、乘积结果及可选部分和逐项计算，并检查乘法、加法、对齐和地址偏移的溢出。通过库提供的工作区机制管理其容量与异步使用期；空间不足时返回相应错误。

##### 3. tilingkey规划策略：

拟按空输出、仅缩放和一般矩阵乘区分执行流程；矩阵乘内部按转置布局、完整块与尾块等必要属性选择处理方式。分支条件只表达计算语义和资源约束，不绑定用例编号或固定矩阵集合。

本设计采用句柄式直接调用，分支信息可通过启动参数传递，不要求引入图算子形式的 tilingkey。需传递的内容包括有效维度、前导维、分块范围、操作类型、复数系数及工作区布局。

#### 3.2.2 kernel侧设计：

数据搬入：按列主序地址 `row + col × ld` 定位复数元素，处理转置与共轭，生成实数矩阵乘所需的输入分量。尾块的无效位置补零。

计算：按统一分块方法执行四个 FLOAT32 矩阵乘，沿 k 维累加。若使用分段归约，先完成同一乘积的部分和合并，再进行复数合成。

写回：按公式合成实部、虚部并施加 alpha、beta；beta 为零时跳过 C 旧值读取。对完整块和尾块分别控制写入范围，输出地址遵循调用方的 ldc。

缩放：k 为零或 alpha 为零时跳过 A、B 数据读取及矩阵乘。alpha 为零的结果按任务书进行位精确校验，复数缩放的运算顺序、舍入及特殊值处理须与指定参考规则一致。

同步：为输入搬运、矩阵乘、结果合成及写回建立明确依赖；若阶段间共享片上缓冲或工作区，须确保所有消费者完成后再复用。

## 算子约束限制

仅设计单个 COMPLEX64 矩阵乘，不包含广播、批量接口及超出前导维语义的任意非连续布局。alpha、beta 位于主机，A、B、C 位于设备。除 C 输入输出原地更新外，不承诺输入与输出重叠的行为。

不要求跨运行逐位确定性，但每次结果均须满足相应精度要求。NaN、Inf 及带符号零按官方要求与对标接口核查；有限值误差规则不直接用于替代特殊值判定。

版本适配、可用内存、索引范围及工作区容量均属于实际实现的边界，不能因维度参数非负就承诺任意规模都可执行。

## 精度标准/性能标准

| 验收标准 | 描述 | 标准来源 |
| --- | --- | --- |
| 精度标准 | COMPLEX64 的实部、虚部分别按 FLOAT32 比较：rtol = 2^-10，atol = 2^-16，匹配比例至少 0.99；同时检查最大绝对误差限制 1e-2 或 32 × ULP，具体适用规则按官方标准及测试指导固定 | 官方任务书 §3.2 及其引用的生态算子精度标准 |
| 特殊分支精度 | alpha = (0,0) 且指针非空时，`C = beta × C` 按 EXACT 位精确校验 | 官方任务书 §3.2 |
| 性能标准 | Ascend 950PR 上先预热，再有效采样超过 50 次并取平均；256、512、1024 阶 N/N 方阵且 alpha=(1,0)、beta=(0,0) 的平均单次耗时分别不高于 36.25、68.29、413.52 微秒；其余用例按配套性能标准判定 | 官方任务书 §3.3 与配套测试指导 |
| 内存标准 | 任务书不设单独内存性能门槛；设计验证仍检查越界、填充区破坏及工作区使用情况 | 官方任务书 §3.4、§3.5 |

逐元素有限值比较采用 `|actual - golden| ≤ atol + rtol × |golden|`。对实部、虚部分别统计匹配比例及最大误差，均满足要求才判定用例通过。最大误差规则需在测试前明确，不得根据结果临时选择宽松门槛。

计划采用 ops-blas 的 CSV 与 GTest 测试方式调用公共接口。相同输入分别由 Netlib `cblas_cgemm` 和 OpenBLAS `cblas_cgemm` 生成参考输出，记录参考库及版本，独立保存两套判断；Netlib 保留为任务书指定参考，OpenBLAS 作为用户要求的独立评估。出现参考差异时分析差异，不修改容差或合并为一个通过结论。

计划覆盖全部 N/T/C 组合、矩形与方形、零维、单位维、小质数、对齐边界、前导维填充及地址偏移，并围绕分块或分段边界选取相邻尺寸。补充非法枚举、负维度、非法前导维和空指针等负向输入，核对错误返回与边界行为。

按任务书为矩阵及系数安排均匀分布和正态分布各占一半，实部、虚部独立采样；覆盖零、一、纯虚系数、大值以及 NaN、Inf。保存输入生成规则及随机种子，便于复现，但算子设计不依赖这些测试信息。

性能测试覆盖配套用例及代表性通用形状，计时范围包含一次接口运算所需的输入整理、矩阵乘与输出合成，明确预热、同步及采样方法。精度与速度分别判定；性能计时之外检查资源使用、填充区保护和异步结果读取。
