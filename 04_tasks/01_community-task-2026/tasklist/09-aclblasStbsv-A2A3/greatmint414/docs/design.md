**aclblasStbsv 算子设计文档**

# 需求背景

## 需求来源

依据 [aclblasStbsv 算子开发任务](https://www.hiascend.com/activities/task-center/details/29c59d7ef9fa4aa8ad26b82969c5e2b6)及其[官方任务书](https://www.hiascend.com/p/resource/202609/1e300361cae649f598bbefe9c522464d.zip)，面向 Atlas A2/A3 设计单精度实数三角带状方程组求解算子。文档结构遵循社区[算子设计文档模板](../../../../resources/design_template.md)，描述拟采用的设计与验证要求。

## 背景介绍

### Stbsv算子实现设计

Stbsv 求解 `op(A) × x = b`，其中 A 为上三角或下三角带状矩阵，输入向量 x 存放右端项 b，调用后原地保存解。带状存储仅保留主对角线及一侧的 k 条对角线，避免存储完整矩阵。

拟采用 Ascend C，在 ops-blas 的句柄与执行流机制下直接启动计算，支持不转置、转置、单位对角和正负向量步长。实现范围为 `blas/tbsv/arch22/`，测试范围为 `test/tbsv/stbsv/arch22/`。

### Stbsv算子接口与能力分析

公共接口与任务书保持一致：

```cpp
aclblasStatus_t aclblasStbsv(
    aclblasHandle_t handle, aclblasFillMode_t uplo,
    aclblasOperation_t trans, aclblasDiagType_t diag,
    int n, int k, const float* A, int lda, float* x, int incx);
```

| 参数 | 参数含义 | 数据类型 | 存储位置与约束 | 形状 |
| --- | --- | --- | --- | --- |
| handle | 库上下文及执行流 | aclblasHandle_t | 有效的主机侧句柄 | 标量 |
| uplo | 原矩阵的上、下三角带选择 | aclblasFillMode_t | 主机侧 UPPER / LOWER 枚举 | 标量 |
| trans | 矩阵操作 | aclblasOperation_t | 主机侧 N / T / C 枚举；实数 C 与 T 等价 | 标量 |
| diag | 是否按单位对角处理 | aclblasDiagType_t | 主机侧 UNIT / NON_UNIT 枚举 | 标量 |
| n | 矩阵阶数与向量逻辑长度 | int | 主机侧，n ≥ 0 | 标量 |
| k | 主对角一侧的带宽 | int | 主机侧，k ≥ 0 | 标量 |
| A | 三角带状矩阵 | const float* | 设备侧只读，列主序；n > 0 时非空 | 物理存储 lda × n |
| lda | 相邻存储列的间隔 | int | 主机侧，lda ≥ max(1, k+1)，以 float 元素计 | 标量 |
| x | 输入右端项，原地输出解 | float* | 设备侧；n > 0 时非空；不得与 A 重叠 | 逻辑长度 n |
| incx | 向量逻辑元素间隔 | int | 主机侧，incx ≠ 0，可正可负 | 标量 |

### Stbsv算子功能分析

`trans=N` 求解 `A × x = b`，`trans=T/C` 求解 `Aᵀ × x = b`。转置改变求解方向，不改变调用方提供的原矩阵带状存储。

`diag=UNIT` 将对角视为 1，不读取或修改 A 的对角位置；`diag=NON_UNIT` 使用实际对角值。A 始终只读，仅覆盖 x 的逻辑元素，步长间隙保持不变。不涉及广播、批量输入或额外缩放系数。

# 需求分析

## 需求描述

在 CANN 9.1.0 环境下设计符合任务书及 cuBLAS Stbsv 语义的 A2/A3 实现。求解过程保留三角依赖关系，利用带内更新的并行性减少计算与搬运开销，不展开完整矩阵或显式求逆。

## 需求拆解

功能：覆盖上、下三角，N/T/C 操作及单位、非单位对角组合，结果写回原向量。

布局：正确解释列主序带状存储、前导维填充和正负步长，避免访问带外、无效三角区域及单位对角元素。

边界：支持空问题、单元素、对角矩阵、窄带、满带和非对齐尺寸；参数检查与空问题返回顺序明确。

计算：按依赖顺序求解主元，在同一主元对应的独立更新范围内进行批量运算，处理片上空间不足和尾部数据。

精度：使用 FLOAT32 计算，对照任务书指定的 Netlib BLAS `stbsv`，单独核查特殊值与不同累加顺序的影响。

性能：由 n、k、布局和可用存储选择处理方式，减少重复读取与启动次数，不按测试编号、随机种子或固定尺寸清单选择实现。

# 详细设计

## 算子分析

### 数学公式

以下下标从 0 开始。以 `a(i,j)` 表示原矩阵的数学元素，A 表示带状存储数组：

```text
UPPER：a(i,j) = A[j × lda + k + i - j]，max(0,j-k) ≤ i ≤ j
LOWER：a(i,j) = A[j × lda + i - j]，j ≤ i ≤ min(n-1,j+k)
```

有效三角带之外的数学元素为零，不从存储填充区读取。单位对角时 `a(i,i)=1`，覆盖上述对角寻址规则。即使 k 大于 n−1，上三角对角的存储行仍为 k，不得改用有效带宽替换这个偏移。

向量以传入指针作为物理缓冲区起点：

```text
start = 0                         ，incx > 0
start = (n-1) × (-int64(incx))      ，incx < 0 且 n > 0
p(i)  = start + i × int64(incx)
b(i)  = 调用前的 x[p(i)]
```

令 `M=op(A)`、`d(i)=1`（UNIT）或 `M(i,i)`（NON_UNIT），则：

```text
M 为下三角：x(i) = (b(i) - Σ M(i,j) × x(j)) / d(i)
                         j = max(0,i-k), …, i-1
                         i 按 0, …, n-1 求解

M 为上三角：x(i) = (b(i) - Σ M(i,j) × x(j)) / d(i)
                         j = i+1, …, min(n-1,i+k)
                         i 按 n-1, …, 0 求解
```

| 原矩阵 uplo | trans | 求解方向 |
| --- | --- | --- |
| LOWER | N | 从前向后 |
| UPPER | N | 从后向前 |
| UPPER | T / C | 从前向后 |
| LOWER | T / C | 从后向前 |

单位对角省略除法。一般有限值采用上述公式；特殊值的实际运算和条件跳过遵循 [Netlib Stbsv 参考](https://www.netlib.org/blas/stbsv.f)，不能仅凭实数代数等价变换推定浮点特殊值行为相同。

### 支持数据类型

A、输入右端项、输出解及计算中间量采用 FLOAT32。维度、带宽、步长与前导维为接口规定的 int；地址偏移、容量及对齐计算提升到 64 位并检查溢出。不默认使用低精度格式或近似倒数代替除法。

### 支持形状

支持满足接口约束的 n、k 和 lda，矩阵物理存储为 lda × n。n > 0 时向量物理跨度至少为 `1+(n−1)×abs(int64(incx))` 个元素；n=0 不访问矩阵和向量。

计算时实际依赖长度不超过 `min(k,n−1)`。任务书接口只要求 k ≥ 0；配套测试以 k ≤ n−1 为主要范围，设计不据此增加 k < n 的接口限制。实际规模同时受可用设备内存和安全地址范围约束。

## 算子实现

### 实现方案

拟采用“参数检查—带内数据搬入—有序求解与更新—按步长写回”的流程。N 路径求出当前分量后，更新尚未求解的右端项；T/C 路径利用已求解分量完成内积与除法。两种方式均按原矩阵列读取，不展开完整矩阵。

#### 3.2.1 host侧设计：

先检查 handle，空句柄返回 `ACLBLAS_STATUS_HANDLE_IS_NULLPTR`；再检查枚举、n、k、lda、incx，非法参数返回 `ACLBLAS_STATUS_INVALID_VALUE`。容量与地址计算使用 64 位整数并检查溢出。

通过标量检查后，n=0 直接返回成功，不访问 A、x；n>0 时两者必须非空，包括 k=0 且 UNIT 的情况。调用方保证容量足够且 A、x 不重叠。

将 C 归并到转置路径，根据输入布局和平台资源生成分块参数，所有设备操作排入 handle 绑定的执行流。

##### 1. 分核策略：

k=0 且 NON_UNIT 时，按独立元素均衡分核，核数由有效分块数和平台资源确定；UNIT 时完成参数检查后保持 x。

k>0 时，使用一个计算核按依赖顺序推进前代或回代，核内并行更新当前带内向量。当前更新完成后才处理下一主元，不将相邻行作为独立任务分核。

##### 2. 数据分块和内存优化策略：

向量可完整容纳时保留在片上，否则缓存活动窗口；窗口仍超出容量时，按主元分段读取、更新和写回。矩阵仅搬运有效带内数据，向量按 p(i) 处理连续或正负跨步布局。

设 U 为可用片上容量，W 为向量缓存长度，B 为系数段长，q 为系数缓冲数量（1 或 2），R 为其他预留空间。按 32 字节对齐后的保守预算为：

```text
align32(4W) + q × align32(4B) + align32(4B) + R ≤ U
```

各项对应向量、系数、中间结果和预留空间。复用生命周期不重叠的缓冲，在容量范围内增大分块以减少搬运。

双缓冲用于系数预取与计算重叠，复用前等待旧数据使用结束，计算前等待新数据就绪。尾块仅处理有效元素，不读取带外或 UNIT 对角，不覆盖 x 的步长间隙。

##### 3. tilingkey规划策略：

区分空问题、单位对角恒等问题、独立对角求解和一般带状求解；一般路径按转置、三角方向、对角类型、步长和缓存方式选择实现。

本算子采用句柄式直调，通过启动参数传递维度、原始 k、lda、incx、向量起点、求解方向及分块信息，不强制引入图算子的 tilingkey。

#### 3.2.2 kernel侧设计：

N 路径取当前残差 r(j)，为零时按 Netlib 规则跳过本列除法与更新；否则求得 x(j)，对带内尚未求解位置执行 `r(i) = r(i) − a(i,j) × x(j)`。同列更新可并行，列间保持依赖顺序。

T/C 路径从 b(j) 中逐项减去已求解分量的贡献，再按对角类型处理除法。UPPER 列按 i 递增、LOWER 列按 i 递减累加；改变归约顺序须先验证精度与特殊值行为。

纯对角路径沿用相同规则，UNIT 不读取对角。所有路径只写 x 的逻辑位置。一般求解优先单次启动完成，窗口回写后须保证结果可见，再进入下一依赖阶段。

## 算子约束限制

本设计仅覆盖 FLOAT32 单矩阵、单右端项三角带求解，不提供广播、批量接口或超出 lda、incx 约定的任意布局。A 与 x 不得重叠；A 的带外区域、填充区及 UNIT 对角不参与计算。

NON_UNIT 求解要求问题非奇异，不增加奇异性或近奇异性检测，也不承诺奇异问题存在有效解。病态输入须分别分析数值误差与参考行为，不通过修改矩阵、对角值或放宽门槛掩盖差异。

调用方须维持输入输出的有效期，并在读取结果前同步绑定的执行流。设备可用内存不足或内部资源申请失败按库约定返回错误。不同运算顺序不要求逐位一致，但均须满足任务的精度规则。

# 可维可测分析

## 精度标准/性能标准

采用 ops-blas 测试框架，以 Netlib BLAS `stbsv` 为参考，使用相同矩阵与初始右端项比较输出。精度判定遵循任务书及生态精度标准，特殊值单独核查。

覆盖各参数组合、正负步长、不同带宽、前导维填充、分块边界及非法输入。通过哨兵值检查单位对角和无效区域不参与计算，确认矩阵及向量间隙未被改写。

性能按任务书与配套测试指导，在预热后统计完整调用的平均设备耗时。每次调用前恢复原始右端项，计时覆盖算子内部的数据整理、求解和写回。分别记录 A2/A3 的实际验证范围。

## 兼容性分析

保持 ops-blas 接口、状态码及执行流约定，OP_C 与 OP_T 等价。实现限定于 Stbsv 的 arch22 目录，不影响其他算子，并保持正负步长、原地输出、单位对角和有效访问范围的语义一致。
