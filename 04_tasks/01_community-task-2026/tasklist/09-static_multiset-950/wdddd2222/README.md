# static_multiset 容器开发（950）

贡献者：GitCode 用户 [wdddd2222](https://gitcode.com/wdddd2222)（putao）。

本目录提交“9月社区任务-multiset容器开发(950)”的设计文档，目标是在 Atlas 950 上以 Ascend C 实现支持 I32/I64 的静态多值集合。

- [设计文档](docs/design.md)说明接口定义、功能语义、实现方案、测试方法及待评审确认的确定性要求。
- [任务详情](https://www.hiascend.com/activities/task-center/details/214f40e300a347c7b21e445fa8671e62?menu=tasks)提供官方任务书及验收测试附件。
- [任务讨论帖](https://gitcode.com/cann/ops-collections/discussions/3)用于任务进展与技术讨论。
- 容器实现与测试的目标仓为 [cann/ops-collections](https://gitcode.com/cann/ops-collections)。

本次提交仅包含设计材料，不包含实现代码或设备测试结果。
