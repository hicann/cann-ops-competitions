# 需求背景（required）

## 需求来源

社区任务 aclblasCtrmm_A2A3，完整要求见项目随附任务书。

## 背景介绍与功能分析

complex64、列主序三角矩阵乘，实现 C=alpha×op(A)×B 或 C=alpha×B×op(A)。
Host 句柄式接口直接调用 Ascend C kernel，部署目录为 ops-blas/blas/trmm/arch22。
接口及全部参数契约见正式算子 README；按 side、uplo、trans、diag 处理矩阵结构。
零维为 no-op；零 alpha 不读取 A/B；单位对角不读取；允许完整 B=C、拒绝不支持的重叠。

# 需求分析（required）

## 需求描述与拆解

实现复数三角乘完整接口、严格 Netlib 精度、五项主性能要求以及可复现的 A2/A3 自验证。
不涉及广播，m/n 为运行时矩阵尺寸；空输入、非法参数与非有限值必须保留规定语义。

## 外部依赖与环境

依赖 CANN 9.1.0、Ascend C Matmul/Vector、ops-blas handle/workspace/common helper。
复用仓库的复数 BLAS3 tiling、矩阵乘配置、同步与交织 helper，不改公共接口语义。
验证使用 GTest、CSV、私有 Netlib BLAS、msprof；此直调算子不需要 PyTorch/torch_npu。
核心数与 UB 容量运行时查询；不将当前 24 AIC/48 AIV 固定写成设备资源常量。

# 详细设计（required）

## 算子分析

数学公式为 C=alpha×op(A)×B 或 C=alpha×B×op(A)，支持 complex64。
A 的阶数由 side 决定，B/C 为 m×n，允许 leading dimension padding，无额外广播或视图。

## 算子实现：Host 侧设计

Host 校验参数、查询核心/UB、计算工作区和 tiling，选择零输出、有序路径或 Cube 路径。
本实现使用 kernel 直调和结构体 tiling，不注册 ACLNN tiling key；分支由明确参数和设备标记决定。

## 算子实现：Kernel 侧流程

1. Host 检查句柄、枚举、尺寸、步长、指针和地址范围，处理零维与零 alpha。
2. 非单位 alpha、原地调用等进入有序补偿路径；符合条件的极小矩阵与16/32/64阶采用直接向量计算，
   其他普通非原地输入进入 Cube 路径。直接路径也保留输入风险检查和有序回退。
3. 打包仅加载有效三角元素，UNIT 对角直接置 1，转置/共轭按实际参数处理。
4. 打包时检查有效实虚部指数；幅值至少 16、Inf 或 NaN 设置每核独立风险标记。
5. 普通短归约采用三乘法：P=Ar×Br，Q=Ai×Bi，S=(Ar+Ai)×(Br+Bi)，
   输出实部 P-Q、虚部 S-P-Q。归约长度 d≥2048 且不进入原有共轭前缀修复路径时，
   改用四乘法：P=Ar×Br，Q=Ai×Bi，R=Ar×Bi，S=Ai×Br，输出实部 P-Q、虚部 R+S。
   四乘法按 K=512 分段，缩短单次 FP32 点积累加长度；按 side 调整矩阵顺序，再应用 alpha。
6. 长规约的 LEFT/UPPER/C/NON_UNIT、alpha=1、非原地且 ldc=m 分支，
   在满足前缀修复条件时共享 Cube 前缀结果，对幅值筛选出的输出重算有序尾段。
   该路径的前缀与尾段算法相互配合，保持原三乘法及原 K 分块，不混用新的四乘法路径。
7. 若设备风险标记非零，有序计算直接读取原始输入并覆盖输出；无风险时入口快速返回。
   回退对矩形、转置、单位对角和独立 padding 有额外测试，不按测试编号分流。

## 分核、分块、内存和同步

Cube tile 为 128×128、base K=64；128 对齐的临时 leading dimension 由实际尺寸计算。
m/n 至少一个不超过 256 时融合 A/B 打包和分量求和，降低启动开销。
向量块默认2304，使2251行的窄矩阵完整列可在同一块处理；片上补零后一次写出。
右侧窄矩阵由Cube处理转置，输出合并与异常回退共用一个内核。
16/32/64阶的直接向量路径使用紧凑行块、四列复用和实际K长度归约。
128行、列数不超过128且临时矩阵与输出均连续时，输出展开为连续区间，按四个复数对齐分配给AIV。
v36将满足左乘分流条件的128阶打包及融合输出放到独立设备编译单元，避免与窄矩阵路径相互影响。
普通打包的风险归约仅扫描实际写入的CHUNK个指数值；此前多扫描的后一半始终为零，阈值不变。
该分支保持原有复数合并公式和异常处理，减少逐列搬运及空闲核心。
修正任务按有效尾段的行块与列重新编号，分配到所有 AIV，避免仅少数核处理尾段。
尾段按 256 个输出、16 个 K 项组织搬运，显式补零，并保持每个输出的参考累加顺序。

工作区由 handle 管理，按矩阵容量、修正临时区、前缀种子和每核标记共同计量；
检查整数乘加及总容量，分配失败返回明确状态。回退的矩形打包容量按两种布局最大值预留。
风险标记每核占 32 字节，kernel 间在同一 stream 上顺序执行；不使用 Host 回读标志或同步分流。
UB 生命周期由局部 TPipe 管理，DMA 与 Vector、标量访问之间使用明确事件与屏障。
原始输入回退先在对齐 scratch 中加载有效元素，再向量重排到系数缓冲，避免不对齐 Vector 地址。

在 4096 有序路径配置下，系数、向量、异常修复及 Select 临时空间预算为 188416 字节，
小于已测设备 UB 196352 字节。工作区和 UB 预算是静态资源分析，不等于内存检测工具通过。
当前向量打包/合并预算为129024字节，直接小矩阵路径预算为93696字节。

## 算子约束限制与数值策略

三乘法、四乘法分段累加的求和次序均与 Netlib 不同，不能用局部性能成功推断全部精度通过。
最初完整快速候选仅 982/1001 通过，因此加入真实输入范围检查和严格回退。
严格路径保持参考顺序并使用补偿乘加；非有限复数乘法采用分类与缩放修复。
输出幅值 1800 筛选及前缀长度属于经实测选择的工程参数，不是任意输入误差界的证明。
不读取参考答案、测试名称、种子、预存修正表；测试阈值和 golden 均保持不变。
大尺寸资源不足时可能返回分配失败；本次范围由随任务自测参数及新增边界测试界定。

## 精度标准、性能标准与验证设计

严格精度同时要求实虚部各 99% 匹配、混合容差 2^-13×(1+abs(ref))、最大绝对误差≤0.01。
功能回归含原有 1000 CSV、48 种原地/独立 padding 组合、24 种触发回退的布局组合。
注册数为 1002，不把内部组合或断言数算成注册测试数。
性能包括正文五项与用户要求继续优化的配套200项，按完整调用计时：10次预热、60次采样、去最大10次平均。
以完整调用所有kernel耗时之和核对上限，检查和回退入口的实际开销均纳入；设备跨度仅作为诊断记录。
每轮保存源码/二进制哈希、构建日志、命令、设备信息、精度结果和 msprof CSV。
A2（910B2）与 A3（910_9382）分别验证，不用跨机差值声称算法收益。
按用户决定使用已测A2/A3环境交付，不以补测910B3阻塞材料整理，未声明华为已批准型号替代。
