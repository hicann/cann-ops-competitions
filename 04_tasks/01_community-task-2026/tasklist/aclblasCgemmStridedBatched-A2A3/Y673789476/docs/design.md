# aclblasCgemmStridedBatched 算子设计文档

# 需求背景（required）

## 需求来源

2026 年 9 月昇腾社区任务：基于 arch22 实现单精度复数带步长批量矩阵乘。
接口、参数顺序及矩阵语义对齐 `cublasCgemmStridedBatched`，使用 ops-blas 的
handle 和 stream 机制，由 Ascend C kernel 直接执行。

## 背景介绍

官方 ops-blas `master` 已有 Ascend 950 的 `aclblasSgemmStridedBatched`，
但 `arch22` 不含 COMPLEX64 的 GEMM Strided Batched 实现。本设计在
`blas/gemm_strided_batched/arch22/` 增加接口实现，并复用仓库公共 handle、
工作空间和测试框架。

# 需求分析（required）

## 需求描述

对每个批次执行 `C_i = alpha × op(A_i) × op(B_i) + beta × C_i`，其中
`A_i = A + i×strideA`、`B_i = B + i×strideB`、`C_i = C + i×strideC`。
stride 以 COMPLEX64 元素计，矩阵均为列主序。`op` 支持 N、T、C，
C 表示共轭转置。各批共用维度、转置参数及复数标量。

## 需求拆解

1. Host 校验 handle、枚举、非负维度、前导维度和必要指针；零维与零批次返回成功。
2. `alpha=0` 时不读取 A/B；`beta=0` 时不读取原 C；处理 Inf/NaN 特殊值。
3. 支持矩阵填充、批间间隔和 A/B 的 stride=0 广播。`strideC=0` 时按批次顺序
   更新同一输出矩阵；C 不得与输入重叠。
4. 对规则与非规则 shape 采用不同计算路径，保持异步 stream 语义。
5. 与 CBLAS `cgemm` 逐批 golden 对比，并测量 910B3 性能。

# 详细设计（required）

## 算子分析

### 数学公式与数据排布

`C_i(r,c) = alpha × Σ_t op(A_i)(r,t)×op(B_i)(t,c) + beta×C_i(r,c)`。
复数采用交错实虚布局。物理矩阵前导维度分别为：
`lda≥max(1, transa=N?m:k)`、`ldb≥max(1, transb=N?k:n)`、
`ldc≥max(1,m)`。

### 支持数据类型与形状

输入、输出均为 COMPLEX64；`m,n,k,batchCount` 为运行时整型参数。
`m=0`、`n=0`、`k=0`、`batchCount=0` 为合法 no-op。

## 算子实现

### Host 侧设计

Host 校验参数后生成 `CgemmSbTiling`，保存 M/N/K、前导维度、步长、转置
模式与复数 alpha/beta。一般 Cube 路径将 M/N/K 对齐到 64；三维均不超过
32 时使用 32 对齐。工作空间容量检查在整数溢出前执行。

输出互不重叠且 alpha=1、beta=0 时按工作空间容量合并批次，库管理空间
采用 128 MiB 分组预算，用户提供的空间按实际容量使用。共享输出保持逐批
顺序更新。各组提交到 handle 绑定的 stream；工作空间扩容由公共 handle
接口管理，空间充足时直接异步下发。

紧凑小矩阵使用向量或 Cube/Vector 协同路径。一般矩阵使用输入打包、
FP32 Cube 矩阵乘、向量输出合成三个阶段。ND2NZ 行跨度超过 65535 时由
直接计算路径处理。alpha=0 不访问 A/B，beta=0 不读取 C 原值。

### 输入与工作空间

一般路径计算 `Cᵀ = op(B)ᵀ × op(A)ᵀ`，使结果平面的连续方向与列主序 C
一致。输入按物理块执行二维 DMA，通过 Gather 完成实虚拆分、N/T/C 映射
和共轭；UB 行间 padding 用于分散访存。紧凑对齐的 N/N 输入使用 8192 个
复数的大块连续搬运。

一般路径每批保存四个输入实数平面与四个乘积平面，空间为
`4 × (2×Mpad×Kpad + 2×Kpad×Npad + 4×Mpad×Npad)` 字节。
各批工作区互不重叠，各组按 stream 顺序复用。

### FP32 计算与同步

四路实乘积在同一 K 循环计算：`RR=ArBr`、`II=AiBi`、`RI=ArBi`、`IR=AiBr`。
输入平面在一次加载后复用两次。一般输出块为 64×64，小尺寸为 32×32；
Ktile 根据对齐采用 128、64 或 32。

MTE1 完成后允许下一段 GM 数据进入 L1；MMAD 完成后允许复用 L0A/L0B。
分别用流水事件保护两种生命周期，使数据搬运与矩阵计算重叠。Fixpipe
完成前不复用对应 L0C 累加器。计算关闭 HF32，保持 FP32 输入及累加。

小方阵协同路径由配对 AIV 打包输入、AIC 计算。复数 A 转换为实数块矩阵
`[[Ar,Ai],[-Ai,Ar]]`，与交错实虚的 B 相乘，直接生成交错的复数输出。
转置与共轭在打包阶段完成，扩展区域置零。批次按输出缓存行边界分组分配，
跨核事件控制输入就绪与有界流水进度。

### 紧凑方阵分派与流水

紧凑方阵协同 kernel 使用 8 字节形状参数，工作区步长由尺寸与对应布局计算。
各路径均使用 FP32 输入与累加，关闭 HF32；转置和共轭通过布局变换与符号位处理。

| 路径 | 数据组织与计算 |
| --- | --- |
| 小矩阵向量路径 | 多批次共用索引表，沿 K 维执行复数外积累加 |
| N/N 规则方阵 | 批量打包增强实数矩阵，L1 批量加载；大批次分块双缓冲 |
| N/T 与 N/C 方阵 | 17～24 阶复用原生 NZ 打包路径；较大尺寸由 AIC 直接加载原始交错复数，计算四个实数分量乘积，AIV 合成为复数结果 |
| 原生 NZ 打包路径 | AIV 生成 L1 可直接使用的 NZ 数据；邻接批次按完整输出缓存行分配；24/32 阶分块预取下一批输入并使用双缓冲输出，Cube 复用整组预加载数据，独立计算各批并交替使用 L0C |
| 均分打包路径 | 配对 AIV 分别承担一半 A 和 B 打包，转置输入只读取所需列；32/40 阶分块合并相邻两批 |
| 原生乘积写回路径 | Cube 将乘积写成原生 NZ，AIV 合并两个批次的读取、重排与精确长度写回 |
| 较大紧凑方阵 | 按 32、48 或 64 的分块宽度处理，分块加载与输出采用有界流水 |

两种向量职责由配对 AIV 同步，跨核计数限制在硬件允许的范围。工作区内各批数据
互不覆盖；输入 L1、L0A/L0B 和 L0C 分别由对应流水事件保护。双 L0C 累加器用于
重叠上一批写回与下一批计算。填充区域指向已初始化的零值，按向量访存位置分散。
原生输出工作区保持 64 字节对齐，批量 DMA 与 Gather 在 UB 内完成重排，输出
仅覆盖逻辑 C 区域。精度回归覆盖分派边界、奇数尾批、输入偏移与输出保护区。

直接加载的 N/T、N/C 路径将四个实数乘积按相邻求和的顺序 Gather，施加共轭符号后
用 `ReducePairElem` 合成为紧凑复数结果，一次连续 DMA 写回。索引先计算两个列，
其余列通过固定地址增量复制；两个列的起点对齐方式同时覆盖奇数与偶数尺寸。
索引运算采用固定向量掩码，批量 N/N 路径采用双 L0C 累加器重叠计算与写回。

### 输出合成与边界

输出阶段向量计算 `real=RR−II`、`imag=RI+IR`，再施加复数 alpha/beta。
单位值、纯实、纯虚和零标量分别处理，避免无效的 0×Inf 运算。

紧凑输出按 64 字节边界划分各核负责的连续范围；起始地址偏移由首尾片段
处理，片段只写逻辑输出。前导维 padding 和批间间隔保持原值。非紧凑输出
根据缓存行隔离条件分配核数。紧凑对齐输出使用连续大块 DMA，其余场景
使用二维输入搬运和精确长度写回。

## 算子约束限制

矩阵须在有效 Device 内存中，C 与 A/B 不得重叠。`strideC=0` 时各批按序读写
同一个 C；其余批间 stride 过小或指针越界不做运行时检查。
当调用方提供的 handle 工作空间小于所需容量时返回分配失败。

# 可维可测分析

## 精度标准/性能标准

| 验收标准 | 目标 | 方法 |
| --- | --- | --- |
| 精度 | COMPLEX64 混合容差：atol=rtol=2^-13、匹配率≥0.99、最大绝对误差≤1e-2 | CBLAS `cgemm` 逐批 golden，覆盖逻辑输出区域 |
| 性能 | 全部 200 条 GPU 基线对应的门槛：gpu_ms×1000/0.8 µs | 每条分别计时，5 次 warmup、12 次有效采样 |

使用 `msprof --ai-core=off --task-time=on` 生成 `op_summary`。
按时间排序后，将一次 API 调用的所有 kernel Task Duration 相加，
排除首次功能调用和五次预热，计算后十二次的均值。ACL stream event
作为另一时间口径单列记录。

CSV 包含 1000 条原精度用例、672 条补充精度用例和 200 条性能用例。
补充覆盖快速路径、输出 padding、DMA 行跨度、随机复数标量、大小写枚举
以及小矩阵九种转置组合。随机矩阵均匀与正态样本各占一半，奇数长度相差
一个样本并由种子交替；18 条随机标量用例中两种分布各 9 条，实虚部独立抽取。
`verify_accuracy.py` 负责构建、运行 GTest、保存日志和核验通过数量。
