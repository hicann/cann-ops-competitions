**aclblasCgemmBatched 算子设计文档**

# 需求背景

## 需求来源

面向 Atlas A2/A3 系列产品、CANN 9.1.0，使用 Ascend C 在 ops-blas 中实现单精度复数批量通用矩阵乘。

## 背景介绍

### CgemmBatched算子实现设计

对每个批次 b 计算 `C[b] = alpha × op(A[b]) × op(B[b]) + beta × C[b]`。矩阵地址由设备侧指针数组指定，批次之间独立，共享维度、前导维和转置标志。设计利用批次和输出块的并行性，并根据片上容量选择驻留或分块计算。

### CgemmBatched算子接口与能力分析

沿用 ops-blas 公共接口，不新增产品专用接口：

```cpp
aclblasStatus_t aclblasCgemmBatched(
    aclblasHandle_t handle, aclblasOperation_t transa, aclblasOperation_t transb, int m, int n, int k,
    const aclblasComplex* alpha, const aclblasComplex* const Aarray[], int lda,
    const aclblasComplex* const Barray[], int ldb,
    const aclblasComplex* beta, aclblasComplex* const Carray[], int ldc,
    int batchCount);
```

| 参数 | 参数含义 | 数据类型 | 存储位置与约束 | 形状 |
| --- | --- | --- | --- | --- |
| handle | 库上下文及执行流 | aclblasHandle_t | 主机侧有效句柄 | 标量 |
| transa、transb | A、B 的操作类型 | aclblasOperation_t | 主机侧 N、T、C 枚举 | 标量 |
| m、n、k | 输出行数、输出列数、归约长度 | int | 主机侧非负整数 | 标量 |
| alpha、beta | 乘积及旧输出的系数 | const aclblasComplex* | 主机侧非空指针 | 各一个复数 |
| Aarray | 各批 A 的设备地址 | const aclblasComplex* const[] | 设备侧指针数组；矩阵列主序、只读 | 长度 batchCount；矩阵 N：lda × k，T/C：lda × m |
| lda | A 的列间隔，以复数元素计 | int | N：≥ max(1,m)；T/C：≥ max(1,k) | 标量 |
| Barray | 各批 B 的设备地址 | const aclblasComplex* const[] | 设备侧指针数组；矩阵列主序、只读 | 长度 batchCount；矩阵 N：ldb × n，T/C：ldb × k |
| ldb | B 的列间隔，以复数元素计 | int | N：≥ max(1,k)；T/C：≥ max(1,n) | 标量 |
| Carray | 各批 C 的设备地址 | aclblasComplex* const[] | 设备侧指针数组；矩阵原地更新，各批 C 不得重叠 | 长度 batchCount；矩阵 ldc × n，逻辑区域 m × n |
| ldc | C 的列间隔，以复数元素计 | int | ≥ max(1,m) | 标量 |
| batchCount | 矩阵数量 | int | 主机侧非负整数 | 标量 |

### CgemmBatched算子功能分析

N 表示不转置，T 表示转置，C 表示共轭转置；共轭通过对虚部取反实现。两输入分别选择操作类型，`op(A[b])` 为 m × k，`op(B[b])` 为 k × n。输入输出均为 COMPLEX64，实部、虚部各为 FLOAT32，交错存储。

输入是 Aarray、Barray、alpha、beta，以及需要时的 C 旧值；输出写回 Carray 指向的各矩阵，不改变指针数组。不要求各批矩阵连续分配，不使用固定批次步长推算地址，也不涉及广播。

# 需求分析

## 需求描述

在 A2/A3 对应的 arch22 实现句柄式 kernel 直调，覆盖全部转置组合、合法前导维填充和边界输入。计算路径仅由接口参数、数据布局、有效工作量与硬件资源决定。

## 需求拆解

功能：逐批完成复数矩阵乘累加，保持统一批次参数和 C 原地输出语义。

布局：逐批读取设备指针；支持列主序及 lda、ldb、ldc 描述的填充，仅更新 C 的有效行列。

边界：m、n 或 batchCount 为零时不计算；k 或 alpha 为零时执行 `C[b] = beta × C[b]`；beta 为零时应直接生成结果，不依赖 C 旧值。

参数检查：检查句柄、枚举、维度、前导维及空指针，返回相应状态。

精度：以 Netlib 逐批生成正式参考，实部和虚部分别按精度标准判断；alpha 为零的缩放单独按位精确标准验证。

性能：通过批次成组、数据驻留、输出分块及搬运计算重叠降低开销，在 A2、A3 上分别验证。

# 详细设计

## 算子分析

### 数学公式

对每个批次，令 `X = op(A[b]) = Xr + iXi`、`Y = op(B[b]) = Yr + iYi`，则：

```text
Zr = Xr × Yr − Xi × Yi
Zi = Xr × Yi + Xi × Yr
Re(C[b]) = ar × Zr − ai × Zi + br × Cr − bi × Ci
Im(C[b]) = ar × Zi + ai × Zr + br × Ci + bi × Cr
```

其中 `alpha = ar + i ai`、`beta = br + i bi`、`C旧 = Cr + i Ci`，矩阵乘沿 k 归约。一般路径分解为四个实数乘积；小矩阵成组路径也可把实虚部及符号整理成等价实数矩阵乘，再提取每个批次的结果。有限精度下不同归约顺序不保证逐位相同。

### 支持数据类型

公共类型为 `aclblasComplex`，包含 real、imag 两个 float。数据整理、实数乘法、累加和复数组合使用 FLOAT32；Cube 路径关闭 HF32 模式，不以低精度转换替代接口精度要求。

### 支持形状

维度由运行时的 m、n、k、batchCount 指定，支持方阵、矩形、非对齐尺寸、退化维度及合法前导维。批次为 uniform，不支持同一调用内各批维度不同。规模受设备内存、工作区和安全索引范围限制。

## 算子实现

### 实现方案

采用“参数检查、输入整理、矩阵乘加、结果写回”的流程。Vector 负责数据整理、小输出计算和复数组合，Cube 负责实数矩阵乘；根据矩阵规模和可用容量选择成组、驻留或分块处理。

#### 3.2.1 host侧设计：

检查句柄、操作类型、维度、前导维及系数指针。空句柄返回 `ACLBLAS_STATUS_HANDLE_IS_NULLPTR`，非法参数返回 `ACLBLAS_STATUS_INVALID_VALUE`；batchCount 大于零时，三个设备指针数组均须非空。

检查通过后，空输出直接返回；k 或 alpha 为零时仅处理 C 的缩放，beta 为一保持不变，为零应直接置零。其余情况根据维度、布局、核数和容量划分任务，申请必要工作区，并在句柄绑定的执行流上启动计算。

##### 1. 分核策略：

利用批次和输出块并行。小矩阵可多批成组，大矩阵按输出区域分块；每块独立完成 k 方向累加，并明确写入归属，避免并发覆盖。分配同时考虑批次数量、尾块和非对齐输出。

##### 2. 数据分块和内存优化策略：

能够放入片上存储的输入优先驻留并复用，容量不足时分块搬运。块大小和成组数量由输入、累加结果、临时空间及缓冲需求共同决定，并兼顾有效工作量。

转置、共轭和实虚部分离在输入整理时完成，无效尾部补零。工作区按实际需求分配，容量不足以处理全部批次时分批执行；地址和空间计算应检查范围，缓冲使用结束后才能复用。

##### 3. tilingkey规划策略：

采用 kernel 直调，通过启动参数区分仅缩放、小矩阵和一般分块路径，不依赖图算子形式的 tilingkey。路径选择依据接口参数、布局和资源条件。

数据检测：主机检查标量及数组外层指针，设备逐批读取矩阵地址；调用方保证有效矩阵指针和存储区。

#### 3.2.2 kernel侧设计：

逐批读取 A、B，按列主序及 N/T/C 语义整理数据，完成复数乘加。一般路径组合四个实数乘积，小矩阵成组时采用等价实数运算并提取各批对应结果。

结果施加 alpha、beta 后仅写回 C 的有效区域，保留列尾填充。beta 为零时应不读取 C 旧值；仅缩放时跳过 A、B 的矩阵数据读取。搬运、计算、写回之间按依赖同步，确保数据就绪后使用、使用结束后复用。

## 算子约束限制

不支持广播或超出 lda、ldb、ldc 语义的任意非连续布局。各 C[b] 不得重叠；除 C 原地更新外，不承诺输入与输出重叠的行为。beta 为零只免除 C 旧值初始化要求，不免除输出存储有效性要求。

不要求跨运行逐位确定性，但结果须符合精度标准。NaN、Inf、带符号零以及不应读取的数据分别验证，不用普通有限值的误差判断代替特殊值语义检查。

# 可维可测分析

## 精度标准/性能标准

| 验收标准 | 描述 |
| --- | --- |
| 精度标准 | COMPLEX64 实部、虚部分别按 FLOAT32 判断：rtol = 2^-10，atol = 2^-16，匹配比例 ≥ 0.99；同时满足最大绝对误差限制 1e-2 或 32 × ULP，具体适用规则在测试前固定 |
| 特殊分支精度 | alpha = (0,0) 且指针非空时，缩放结果按 EXACT 位精确判断 |
| 性能标准 | 先预热，有效采样超过 50 次取平均；逐项不高于对应基线的平均耗时 |
| 内存标准 | 无单独内存性能门槛；验证有效访问范围、填充保护及工作区使用 |

正式参考对每个批次调用 Netlib `cblas_cgemm`，使用相同转置、维度、前导维、系数及原始 C；逐批比较完整逻辑输出，实部和虚部单独统计。有限值逐元素条件为 `|actual − golden| ≤ 2^-16 + 2^-10 × |golden|`，匹配比例与最大误差均满足要求才通过。最大误差规则在测试前固定，不随结果选择较宽门槛。OpenBLAS 和高精度计算可辅助定位误差，不替代 Netlib 的正式判定。

采用 ops-blas 的 CSV 与 GTest 框架调用公共接口。覆盖 N/T/C 的全部组合、矩形、零维、单位维、小质数、对齐边界、前导维填充和地址偏移；在容量切换、工作区切片及成组边界两侧取样，包含尾组、非连续分配的批次矩阵和不同合法地址。

矩阵和系数采用均匀、正态分布，实虚部独立生成，补充零、一、纯虚、大值、NaN、Inf 和带符号零。检查非法枚举、负规模、非法前导维、空指针、零输出与仅缩放；用未初始化或特殊值 C 检查 beta 为零时不依赖旧值，并保护 A/B、指针数组和 C 填充区。

性能按同一实现和参考规则，在 A2、A3 分别测量。计时覆盖一次运算所需的数据整理、矩阵乘及输出合成，参考计算与数值比较放在计时区间外；规定预热、同步和采样方法，按平均耗时判定。910B3 基线用于对应设备比较，设备之间的结果不得互相替代。

## 兼容性分析

保持 ops-blas 公共接口、复数类型、状态码和执行流约定，与 `cublasCgemmBatched` 的参数序列及批次语义对应。实现位于 A2/A3 的 arch22 范围，不改变其他产品线的接口；无新增输出、广播或批次步长参数。
