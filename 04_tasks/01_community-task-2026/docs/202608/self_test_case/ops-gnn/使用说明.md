# 测试用例使用说明

## 目录结构

```
ops-gnn/
├── test/                          # 功能+精度测试（每个算子一个独立文件）
│   ├── conftest.py                # pytest fixture：每个用例后自动清理 NPU 缓存
│   ├── test_fps.py                # FPS 远点采样
│   ├── test_gather_coo.py         # Gather COO
│   ├── test_gather_csr.py         # Gather CSR
│   ├── test_grid.py               # Grid 体素网格
│   ├── test_knn.py                # KNN + KNN Graph
│   ├── test_nearest.py            # Nearest 最近邻
│   ├── test_random_walk.py        # Random Walk 随机游走
│   ├── test_scatter.py            # Scatter 散射归约（6种 reduce）
│   ├── test_segment_coo.py        # Segment COO（5种 reduce）
│   └── test_segment_csr.py        # Segment CSR（5种 reduce）
└── benchmark/                     # 性能基准
    └── run_benchmark.py
```

## 集成

**只需添加开发的算子的文件**，不需要修改其他的文件。

### 测试文件

复制对应的测试文件：

```bash
# 例如只开发 FPS 和 KNN
cp test/test_fps.py ops-gnn/test/
cp test/test_knn.py ops-gnn/test/
```

### 性能测试 (benchmark/run_benchmark.py)

在 `run_benchmark.py` 中**添加三个部分**，不改已有的算子配置：

**1. 添加 shape 配置**（`SHAPES` 字典）：

```python
SHAPES = {
    # ... 已有算子保持不变 ...
    "<算子名>": [
        (" 128 x 3",    (128, 3)),
        ("1024 x 64",   (1024, 64)),
    ],
}
```

**2. 添加工厂函数**（构造输入 tensor）：

```python
def _<算子名>(dims, dtype, device):
    N, F = dims
    return [torch.randn(N, F, dtype=dtype, device=device)]
```

**3. 注册到 `FACTORIES` 字典**：

```python
FACTORIES = {
    # ... 已有算子保持不变 ...
    "<算子名>": lambda d, dt, dev: _<算子名>(d, dt, dev),
}
```

之后用 `--op <算子名>` 即可单独跑性能：

```bash
python3 benchmark/run_benchmark.py --op <算子名>
```

## 运行

### 功能/精度测试

```bash
# 单个算子（按需选择）
pytest test/test_fps.py -v
pytest test/test_gather_coo.py -v
pytest test/test_scatter.py -v

# 一次跑多个
pytest test/test_fps.py test/test_knn.py -v

# 全部算子（如果复制了所有测试文件）
pytest test/ -v
```

### 性能基准

`benchmark/run_benchmark.py` 是独立的 NPU 性能基准测试脚本，直接 `python3` 运行即可，不依赖 pytest。

#### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--op` | 算子名，逗号分隔。不加则跑全部 | 全部 |
| `--iter` | 测量迭代次数 | 100 |
| `--warmup` | 预热迭代次数 | 20 |
| `--reduce` | scatter/segment 的归约方式 | sum |
| `--device` | 运行设备，npu / cpu | npu |

#### 示例

```bash
# 只跑一个算子
python3 benchmark/run_benchmark.py --op fps --reduce sum
python3 benchmark/run_benchmark.py --op gather_coo

# 同时跑多个
python3 benchmark/run_benchmark.py --op fps,knn,scatter

# 跑全部算子（默认reduce=sum）
python3 benchmark/run_benchmark.py

# 换归约方式
python3 benchmark/run_benchmark.py --op scatter --reduce mean
python3 benchmark/run_benchmark.py --op segment_coo --reduce min
python3 benchmark/run_benchmark.py --op scatter,segment_coo,segment_csr --reduce max

# 自定义迭代
python3 benchmark/run_benchmark.py --op fps --iter 200 --warmup 50
```

#### 输出格式

每行一个 shape×dtype 组合，延迟单位毫秒：

```
device=npu  warmup=20  iters=100

xxx
                 shape    float32    float16
------------------------------------------------
               128 x 3    0.761ms    0.753ms
             1024 x 64   65.847ms   66.320ms
            4096 x 128  195.250ms  194.566ms
            8192 x 256 3790.037ms 3260.120ms
```

> 脚本默认使用 `@torch.no_grad()` 和 NPU 设备同步，测量实际 NPU kernel 执行耗时。

| 算子 | `--op` 参数 | 基准 shape |
|------|------------|-----------|
| scatter | `scatter` | 16384×512 ~ 65536×2048 |
| segment_coo | `segment_coo` | N=256K~4096K, seg=16K~64K |
| segment_csr | `segment_csr` | N=256K~4096K, seg=16K~64K |
| gather_coo | `gather_coo` | 16384~262144, idx=65536~1048576 |
| gather_csr | `gather_csr` | N=256K~4096K, seg=512~4096 |
| FPS | `fps` | N=1K~32K, F=3, r=0.25~0.50 |
| KNN | `knn` | 1K×3 k=4 ~ 16K×32 k=16 |
| Nearest | `nearest` | N=M=1K~32K, F=3~64 |
| Grid | `grid_cluster` | N=4M~32M, D=3~64 |
| Random Walk | `random_walk` | E=64K~512K, walk=128~256 |
| Graclus | `graclus_cluster` | V=4~64 完全图 |

## 算子与测试文件对照表

| 算子 | 测试文件 | 对标 | 说明 |
|------|---------|------|------|
| `fps` | `test_fps.py` | `torch_cluster.fps` | 远点采样，欧氏距离平方，支持 multi-batch |
| `gather_coo` | `test_gather_coo.py` | `torch_scatter.gather_coo` | 纯数据搬运，index 必须有序 |
| `gather_csr` | `test_gather_csr.py` | `torch_scatter.gather_csr` | 纯数据搬运，indptr 单调 |
| `grid_cluster` | `test_grid.py` | `torch_cluster.grid_cluster` | 确定性算子，体素网格 |
| `knn` / `knn_graph` | `test_knn.py` | `torch_cluster.knn` | K 近邻 + 图构建，batch 必须已排序 |
| `nearest` | `test_nearest.py` | `torch_cluster.nearest` | 最近邻，1D 输入自动 view |
| `random_walk` | `test_random_walk.py` | `torch_cluster.random_walk` | 随机游走，含随机性固定 seed |
| `scatter_sum/add/mul/mean/min/max` | `test_scatter.py` | `torch_scatter.scatter` | 6 种 reduce，sum=add 等价 |
| `segment_sum/add/mean/min/max_coo` | `test_segment_coo.py` | `torch_scatter.segment_coo` | 5 种 reduce（无 mul），index 有序 |
| `segment_sum/add/mean/min/max_csr` | `test_segment_csr.py` | `torch_scatter.segment_csr` | 5 种 reduce（无 mul），indptr 单调 |
| `graclus_cluster` | `test_graclus.py` | `torch_cluster.graclus_cluster` | 图贪心聚类，含随机性固定 seed |

## 关键注意事项

- 测试默认使用 **NPU 设备 4**，在各测试函数中调用 `torch.npu.set_device(4)`
- `conftest.py` 在每个用例结束后自动调用 `torch.npu.synchronize()` + `torch.npu.empty_cache()`，避免大量用例连续跑时 NPU 设备状态累积导致后续用例失败
- 具体事项详见项目中的文档
- 开发者可以根据实际情况调整测试函数，并反映到自测报告中
