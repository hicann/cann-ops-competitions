# 2026 中国高校计算机大赛—人工智能创意赛（昇腾 AI 创新大赛）

## 🏆 赛事介绍

本目录（`harness-challenge-2026/`）收集 2026“中国高校计算机大赛—人工智能创意赛—昇腾 AI 创新大赛”参赛队伍的 Skill 作品，每支队伍使用独立的子目录提交与维护。

赛事面向高校开发者，围绕昇腾 AI 技术开展模型迁移与优化实践。参赛团队需基于昇腾进行 Agent Skill 场景开发，在指定模型上进行优化创新，展示 Skill 在实际应用场景中的价值。

**赛事官网**：[昇腾 AI 创新大赛](https://www.chaspark.com/#/s/C4-AI-2026-Ascend)

> 以下赛事信息依据 2026 年 9 月 30 日保存的官方报名页整理；日程、规则及交付要求如有调整，以赛事官网最新通知为准。

| 赛题名称 | 赛题说明 |

## ⚖️ 参赛要求

- 面向中国内地及港澳台地区高校在读学生，含专科、本科、硕博研究生等，不限专业。

## 📁 仓库提交规范

本仓库仅接收 Skill 文件夹，包括 `SKILL.md` 及 Skill 使用所需的脚本、参考资料和资源文件。以下目录组织、命名及 Pull Request 流程为本仓库约定。

### 目录结构

在 `harness-challenge-2026/` 下以团队名称建立子目录，每支队伍一个目录。推荐按以下结构组织，辅助文件可根据作品实际需要增减：

```text
harness-challenge-2026/
├── README.md                          # 本赛事提交说明
├── {TeamName}/                        # 团队目录
│   └── {SkillName}/                   # Skill 目录，可包含多个
│       ├── SKILL.md                   # Skill 使用说明与执行步骤
│       ├── scripts/                   # 辅助脚本（可选）
│       ├── references/                # 参考资料（可选）
│       └── assets/                    # 模板等资源文件（可选）
└── {AnotherTeam}/
    └── ...
```

### 命名规则

- `{TeamName}`：团队名称，建议与报名队名保持对应，使用英文、数字和短横线，例如 `team-example`。
- `{SkillName}`：Skill 名称，建议使用简短、能体现用途的名称。
- 同一队伍后续更新沿用原有目录，多个 Skill 统一放在本队目录内。

### Skill 使用说明

在各 Skill 的 `SKILL.md` 中说明用途、适用场景、环境依赖、使用方式与执行步骤。必要的辅助脚本和资源随 Skill 一并提交，无需另行提交团队 README 或完整赛事报告。

### 提交步骤

1. Fork 本仓库，在本赛事目录下创建团队子目录。
2. 将 Skill 文件夹放入本队目录，包含 `SKILL.md` 及必要的辅助文件。
3. 按 `SKILL.md` 验证使用流程，确保依赖、路径和执行步骤完整。
4. 提交 Pull Request，在标题中注明赛事与团队名称，在描述中说明 Skill 内容及验证结果。
5. 后续修改继续更新本队目录，并在 Pull Request 中说明变更。

请仅提交本队 Skill 相关文件，不修改其他队伍的内容。Skill 依赖的数据集或模型权重请在使用说明中提供获取方式，不放入本仓库。

仓库 Pull Request 用于 Skill 归档；其他复赛材料报送及评测操作请按[赛事官网](https://www.chaspark.com/#/s/C4-AI-2026-Ascend)的要求完成。
