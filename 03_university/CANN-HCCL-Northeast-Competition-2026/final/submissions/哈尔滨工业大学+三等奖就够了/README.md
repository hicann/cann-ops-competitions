## 作品说明

Scatter（数据分发）将根节点输入均分，每张计算卡接收对应分片。根据实际拓扑分组，使用 CCU 通信引擎完成元数据发布、分片读取和完成通知，包含元数据交错发布优化。支持任意根节点、合法零长度及原地输出，并保持数据读取与完成通知的先后关系。

## 环境与构建

目标环境为 Linux、CANN Toolkit 9.1.0、Ascend 950 赛事评测环境。按官方模板 README 安装对应架构的 Toolkit 并加载环境变量后执行：

```bash
cd code
source /usr/local/Ascend/cann/set_env.sh
bash build.sh
```

自定义安装位置请相应修改环境脚本路径。工程目录、依赖与构建参数详见 [模板说明](code/README.md)。
