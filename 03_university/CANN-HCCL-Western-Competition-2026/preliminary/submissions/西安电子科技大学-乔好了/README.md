## 代码说明

本目录保存初赛 AllReduce 通信算子的可复现源码与构建配置。工程结构与原始赛题模板保持一致：`include/` 包含公共头文件，`op_host/` 包含 Host 侧逻辑，`op_kernel_aicpu/` 包含 AICPU 内核逻辑；可使用 `bash build.sh` 构建。

初赛最终合并版已完成 Debug/Release 构建，并保留了 4 B、512 KiB 和 400 MiB + 4 B 的 Checker 成功证据。512 MiB 的合并版验证未在限定时间内完整结束，故本归档不对此尺寸作通过声明。
