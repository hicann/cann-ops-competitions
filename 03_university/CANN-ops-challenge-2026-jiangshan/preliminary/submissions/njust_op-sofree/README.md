## 算子实现介绍

本实现基于 Ascend C 自定义算子工程完成 Erf 算子的 float32 ND 输入输出支持。Host 侧完成 shape、dtype 推导与 tiling 下发，Kernel 侧按输入元素规模进行切分，覆盖非 32 字节对齐尾块场景，并针对 910B 平台的向量计算和数据搬运开销进行分块调度优化。
