## 实现思路

本算子实现 Ascend 平台上的 `Erf` 自定义算子，输入为 `x`，输出为 `y`。当前代码注册的数据类型为 `float32`，数据格式为 `ND`，Host 侧 shape 推导直接将输出 shape 设置为输入 shape，因此输出尺寸与输入尺寸保持一致。

Host 侧首先读取输入元素总数 `totalLen`，并根据输入规模选择调度模式和 block 数。当 `totalLen <= 1` 时，算子使用 `ERF_SCH_MODE_SINGLE`，只启动 1 个 block，并在 Kernel 侧进入单元素特化路径。其余规模使用 `ERF_SCH_MODE_GENERAL`，Host 侧预先计算每个核心的对齐长度、完整核心数量、尾块长度以及尾块是否需要 pad 搬运，再通过 tiling 数据传递给 Kernel。

通用路径的数据切分采用分层策略。小规模输入 `totalLen <= 8192` 时以 8 核为上限，并按 8 个 `float32` 元素对齐；中等规模输入 `8192 < totalLen <= 131072` 时以 32 核为上限，并按 128 个 `float32` 元素对齐；更大规模输入会读取平台 AIV 数，以 `ceil(totalLen / 8192)` 和 AIV 数的较小值作为核心数，并继续按 128 个 `float32` 元素对齐。这样可以在小 shape 的调度开销和大 shape 的并行度之间取得平衡。

Kernel 侧通过模板参数 `DT_X` 和 `schMode` 进行编译期分派。`DT_X` 当前只选择 `C_DT_FLOAT`，`schMode` 在 `ERF_SCH_MODE_SINGLE` 与 `ERF_SCH_MODE_GENERAL` 之间选择。单元素路径由 `RunSingle` 处理；通用路径中，Kernel 根据 `blockIdx` 判断当前 block 是完整块还是尾块，并得到当前核心的 GM offset、处理长度和 pad 标记。

通用 Kernel 根据每核处理长度继续选择不同执行路径。当 `coreLenAligned <= 1024` 时使用 `RunLocalPade`，在本地 VECCALC 张量中完成搬入、Pade 近似计算和写回；当 `coreLen <= 8192` 时使用 `RunLocalTaylor`，直接使用本地张量完成 Taylor 多项式近似；当单个核心处理长度超过 8192 个元素时使用 `RunPipeline`，通过输入、输出双缓冲队列和 8192 元素 tile 粒度组织 CopyIn、Compute、CopyOut 流水，以提高大规模输入下 MTE2 搬入、VEC 计算和 MTE3 写回的重叠程度。

数据搬运方面，完整块优先使用普通 `DataCopy`。Host 侧通过对齐切分让大多数核心的起始位置和处理长度满足对齐要求；只有尾块长度不是 8 元素对齐时，Kernel 才根据 `tailNeedPad` 使用 `DataCopyPad` 完成非对齐搬入或写回，从而减少非对齐搬运路径的使用频率。

精度计算没有调用通用标量 `erf` 数学库函数，而是使用向量化近似表达式。Taylor 路径先将输入裁剪到 `[-2.23908424, 2.23908424]`，令 `t = x * x`，再使用奇函数形式 `erf(x) ~= x * (C0 + C1*t + C2*t^2 + C3*t^3 + C4*t^4)` 进行近似，系数为 `C0=1.12432802`、`C1=-0.357585311`、`C2=0.0883001909`、`C3=-0.0124759655`、`C4=0.000739837822`。实现中采用 Horner 形式组织乘加，主要由 `Mins`、`Maxs`、`Mul`、`Muls`、`Adds` 等向量指令组成。

Pade 路径主要用于单元素和小块场景。该路径先将输入裁剪到 `[-2.3, 2.3]`，再计算 `erf(x) ~= x * (A0 + A1*t + A2*t^2) / (1 + B1*t)`，其中 `A0=1.13231867`、`A1=-0.00209840`、`A2=0.00397027`、`B1=0.34692688`。相比 Taylor 路径，Pade 路径表达式更短，但包含一次向量除法，适合当前实现中较小数据块的处理。

整体上，该算子的优化重点是：Host 侧完成尽可能多的切分和尾块预计算，Kernel 侧减少除法、取模和复杂分支；完整块尽量走对齐 `DataCopy`，非对齐尾块单独使用 `DataCopyPad`；小块使用本地快路径降低队列管理开销，大块使用双缓冲流水提升吞吐；误差函数计算转换为连续向量指令执行，在精度和性能之间取得平衡。
