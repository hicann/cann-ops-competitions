## 算子实现介绍

本提交实现预选赛 Erf 算子。Host 侧根据输入规模进行对齐切分和多核调度，Kernel 侧结合向量计算、轻量小块路径与尾部处理完成非对齐场景兼容。

### 精度优化策略

- 使用 Ascend C 向量 Erf 接口完成主体计算。
- 对不足向量对齐长度的尾部元素进行单独处理。
- 覆盖非 32 字节整倍数输入场景。

### 性能优化策略

- 对不同输入规模选择合适的核数，降低小 shape 调度开销。
- 对较小的单核数据块使用轻量 Buffer 路径。
- 对大块数据使用双缓冲队列，尽量重叠搬运与计算。
