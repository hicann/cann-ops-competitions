## 算子实现介绍

### 1. 算子整体实现思路

基于 AscendC 实现 Erf 自定义算子，Host 侧负责算子注册、形状推导与按输入规模的 Tiling 分核；Device 侧采用分块流水线处理全局内存数据，针对 float 类型使用无指数有理函数近似替代内置实现。

### 2. 精度优化策略

采用论文 2504.05068 的 exp-free 近似方案，参数 (M, N, K) = (0, 3, 2)，通过有理函数近似与平方根组合计算 erf，避免指数运算；尾块使用 COUNTER 掩码并保证临时缓冲区 32 字节对齐。

### 3. 性能优化策略

- Host Tiling：小 Tensor 单核、中等规模提升并行、大规模按 Tile 与 AIV 核心数动态分核
- Device：小向量快速路径、8192/12288 分块、双缓冲重叠 MTE 与计算
- 数据搬运：对齐块用 DataCopy，非对齐边界用 DataCopyPad
