# CANN 启航营 & 复旦校内自办赛

![banner](./images/banner.png)

## 活动简介

为进一步提升同学们在"人工智能 + 国产化"方向的创新实践能力，复旦大学开放原子开源社团联合 CANN 开源社区推出 CANN 启航营 & 复旦校内自办赛。

本次活动聚焦昇腾 AI 生态与国产化算子开发实践，结合理论授课、线上竞赛与作品答辩，带领同学们系统学习 Ascend C 开发体系与算子优化核心技术，深入理解国产 AI 基础设施的开发流程与底层原理，提升高性能算子开发与工程实践能力。

## 比赛入口

- CANNJudge 比赛链接：https://cannjudge.cn/fdu-aiops/fdu-competition-2026
- 活动详情与报名方式：https://mp.weixin.qq.com/s/bFUP676rZdmyr-Ce7oH0dw

## 赛题说明

本次比赛围绕 Ascend C 算子开发与优化设置题目。题面见 `problems/` 目录：

| 题目 | 参考语义 | 题面 |
| :--- | :--- | :--- |
| Addcmul | `torch.addcmul` | [problems/Addcmul.md](./problems/Addcmul.md) |
| ClipByValue | `torch.clamp` | [problems/ClipByValue.md](./problems/ClipByValue.md) |
| Lerp | `torch.lerp` | [problems/Lerp.md](./problems/Lerp.md) |

参赛同学需在 CANNJudge 平台提交代码并依据平台判定成绩。6 月 6 日答辩前，请按照 [CONTRIBUTING.md](./CONTRIBUTING.md) 将最终代码提交到本仓库，作为代码归档、审核与答辩材料。
