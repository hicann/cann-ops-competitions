## 算子实现介绍（Erf）

### 1. 整体实现思路
逐元素算子 `y = erf(x)`，FP32，目标平台 Ascend 910B。Host 侧根据数据规模决定核数与切分方式，Kernel 侧按每核数据量分三条路径执行：

- **小数据**：无 TPipe，用多项式近似直接算（省去流水建立开销）。
- **大数据**：双缓冲流水线 + 硬件 `Erf()` 指令，搬运与计算重叠。
- **中等数据**：单次搬入搬出 + 硬件 `Erf()`。

### 2. 精度优化
小数据路径用 **奇函数 Padé[2,2] 近似**：`erf(x) ≈ clamp(x·N(x²)/D(x²), -1, 1)`，系数由 scipy 拟合，最大误差 2.5e-4（优于常见公式的 5e-4）。利用奇函数性质省去符号处理，最后 clamp 到 [-1, 1] 防越界。大数据路径直接用硬件 `Erf()` 保证精度。

### 3. 性能优化
- 规模自适应分发：小数据省开销、大数据抢带宽。
- 双缓冲流水线（BUFFER_NUM=2）重叠搬运与计算。
- GM 分级对齐（大张量 512B、小张量 32B），兼顾带宽与多核并行。
- 大数据设 L2 Cache Disable，避免逐元素只读一次的无效缓存。
- 多项式用 Horner 求值，全程仅 13 个算子、1 次 Div。
