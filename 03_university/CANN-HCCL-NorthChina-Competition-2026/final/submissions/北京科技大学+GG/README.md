## 作品信息

- 赛题：AllGather 集合通信算子
- 通信引擎：CCU
- 赛事平台提交编号：`120510`
- 代码目录：`code/allgather_ccu/`

本实现完成 AllGather 操作接口，将通信域内各 Rank 的输入按 Rank ID 顺序拼接，并将完整结果写入所有 Rank 的输出。代码面向决赛给定的 2 × 8、4 × 1 和 8 + 4 三种通信域拓扑，使用 CCU 完成通信任务编排。
