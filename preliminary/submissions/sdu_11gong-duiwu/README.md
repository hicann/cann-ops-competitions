## 算子实现介绍

### 整体实现思路

采用四路径自适应调度策略，根据每核数据量自动选择最优执行路径。核心计算使用 degree-11 奇多项式 `erf(x) ≈ x·P(x²)`，相对误差 Remez 系数，组合误差 6.82e-4，满足双千分之一精度要求。

### 精度优化策略

- 多项式采用相对误差加权 Remez 算法，在 clamp 区间 [-2.6, 2.6] 上均匀分布误差
- 标量路径中直接使用 `__gm__` 指针访问，避免框架引入的额外精度损失
- 零填充策略防止向量运算中未初始化数据的 NaN 污染

### 性能优化策略

1. **标量路径（≤32/核）**：纯标量运算，`__gm__` 指针直接读写，零框架开销
2. **UB 快速路径（33-48/核，8 对齐）**：`LocalMemAllocator` 分配缓冲区，`PipeBarrier + DataSyncBarrier` 同步
3. **手动 Tiling 路径（49-128/核）**：手动构造 tiling 结构体，跳过 `REGISTER/GET_TILING` 宏，小 tile 减少缓冲区浪费
4. **宏 Tiling 路径（>128/核）**：标准 AscendC TQue 双缓冲流水线，多 tile 并行处理

关键技术：SetFlag/WaitFlag 硬件事件同步取代 EnQue/DeQue 开销、DataSyncBarrier 保证缓存一致性、自适应 tileLength 缩减确保单 tile 路径。
